# 01 Express

Навчальний проєкт з Node.js та Express.

## Technologies

- Node.js
- Express
- Nodemon
- ESLint
- JavaScript

## Installation

Clone the repository and install dependencies:

```bash
npm install
```

## Development

To start the development server:

```bash
npm run dev
```

The server will automatically restart when you make changes to the source files.
